# 🎮 Hand Tracking Game Series (v1, v2, v3)

This project is a computer vision-based interactive game using Python, OpenCV, and MediaPipe.  
The game uses real-time camera input to detect your finger/hand and uses it as a controller.

The project is developed in 3 versions, each improving the previous one.

---

## 📁 Project Structure

---

## 🕹️ Game Versions

### 🎯 Game v1 – Basic Version
- Basic camera opens using OpenCV
- Simple finger/hand detection
- Basic gameplay logic
- Minimal or no UI improvements

---

### 🚀 Game v2 – Improved Version
- Better hand tracking accuracy
- Smoother gameplay experience
- Improved graphics/UI
- Bug fixes from v1

---

### ⚠️ Game v3 – Warning / Experimental Version
- Advanced experimental features
- New gameplay ideas tested
- May contain bugs or unstable performance
